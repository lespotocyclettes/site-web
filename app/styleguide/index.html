Fondation CSS

Cette page sert à trois choses. C'est la documentation de la fondation. C'est la page à rouvrir après chaque changement, pour voir si rien n'a cassé. Et c'est la preuve que la fondation marche sans React et sans étape de build. Si un composant n'y figure pas, il n'existe pas.

Asap, pour le texte courant

Asap est une police variable : un seul fichier couvre toutes les graisses, c'est-à-dire toutes les épaisseurs de trait, du maigre au gras.
